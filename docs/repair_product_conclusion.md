## 已确定的一期范围

- 自建 `server/` 成为唯一业务后端，只在本机运行；移除课程接口及 `LOCAL_BACKEND` 分支。继续用开发验证码，不接真实短信。
- 一个 App 按住户/师傅角色切换界面；物业待办、派单与跟进放在网页后台，一期不做物业手机端。
- 住户填写期望上门时段和急单标记；师傅接单时确认时段；改约必须填写原因并记录新旧时段。
- 师傅提交完工后进入待住户确认；住户可确认，或填写未修好原因，回到处理中、保留原工单并计一次返修。三天无操作自动确认。
- 物业待办包含超时未派单、超时未接单、约定时段已过仍未完成、住户反馈未修好；急单优先。
- 住户电话仅在处理中对师傅返回明文，其他状态脱敏。该约束要覆盖列表、详情和写操作响应，不能只在 UI 遮罩。
- 不做推送、报销审批和支付。二期再考虑现场转派、求助和协助师傅；三期再考虑能力分级与费用记录。

## 实施前继续讨论的产品边界

以下是待确认项，不因保存基线而自动定案：

1. **上门时段与修复期限分开。** 上门时间不等于修完时间。一期未记录实际到场时，建议把第三类待办表述为“约定时段已过、工单仍处理中”，用作物业跟进提示，不直接判定违约；是否另设修复期限仍待讨论。
2. **自动确认后的反馈出口。** 要明确超期后住户如何联系物业，以及物业是否能重新打开原单。一期可暂不做复杂申诉，但不能让已完成成为无反馈出口的页面。“三天”按连续 72 小时还是自然日也需明确。
3. **待确认期间的联系路径。** 在电话隐藏的前提下，“未修好”按钮必须清晰；返回处理中后如何通知师傅重新处理、是否重新约定时段，需要一起确定。一期没有推送，不能承诺即时通知。
4. **待办阈值与消除规则。** 未派单按创建时间、未接单按最近派单时间；超时阈值待定。返修次数大于零不等于永远待办，返修重新完工后应退出当前返修待办。同单多个标签如何计数应保持一致。

## 技术实施建议

- 新增状态应使用未占用值，例如 6；现有 App 将 4 识别为已取消，不要直接复用。集中定义状态名称与允许转换。
- 一期继续使用 payload 内 timeline。事件由服务端追加，并记录操作者、时间、原因及状态/时段变更；工单状态、revision、时间线在事务内保持一致。暂不拆事件表。
- 自动确认采用惰性处理，不起定时任务。统一覆盖有权限的列表、详情、统计及写操作；先处理到期状态再分类和计数。自动确认幂等，不能因为后续旧 revision 的 409 抛错而一起回滚。
- 返修保留历史事件，撤销本轮确认截止时间；再次完工时重新起算。师傅报完工时间和最终确认时间分别存储。使用注入时钟测试边界，不实际等待三天。
- 服务端拒绝非回环 HOST，更新 README 中的局域网启动建议；保留 Origin 白名单。鸿蒙使用设备到主机的 HDC 转发，Android 单独配置 ADB reverse，Web 使用电脑回环地址，各端分别验收。
- 删除后端开关时保留本地 token 命名空间，或明确清理旧凭证并重新登录，避免误读课程后端 token。
- 409 后刷新权威数据并保留用户输入；角色查询失败后提供可见重试入口。定位拒绝引导和参考房号说明可作为小范围体验补齐。
- `server/data/`、真实证件照、本地 Key、签名配置和截图日志不进入提交或分发包。回环绑定仅适合使用虚构资料的本机演示；现有媒体 URL 免登录，不能当成真实敏感资料的访问控制方案。

## 原产品研究（后续参考）

原研究考虑让住户、师傅、物业都有适合各自工作的手机界面，共享同一张工单。一期已收敛为住户/师傅共用 App、物业使用网页后台；物业手机端不属于本期。以下能力、协助和费用思路也属于后续候选，不自动进入开发范围。

1. **流程保持短：报修 → 约定上门 → 现场确认并维修 → 交付反馈。** 能当场修就当场修，勘查不强制再跑一趟；电话、照片和视频帮助沟通，不能代替现场确认。材料不足、改约、求助、换人留在原单处理。
2. **急缓、难度、能力分别管理。** 急单优先响应；难度以现场判断为准，再调整人员、工时、材料和交付承诺。师傅按工种分能力层级，结合可用时间和服务范围派单；能力不足直接求助或转交，不能只看好评星级。
3. **每单说明白谁来、去哪、何时来、何时修好。** 记录用户期望、约定到场时段、师傅交付时间和服务地点。未勘查清楚时显示下次反馈时间，不编造完成承诺；改约保留变更记录、同步三端并撤销旧提醒。上门地点默认就是交付地点。
4. **一位主责师傅，可带协助者，物业始终有人跟进。** 没人接单、交接未完成、延误和纠纷进入物业待办。住户可以直接联系师傅，关键约定便捷留档；内部备注与住户可见进度分开。师傅报完工后，住户仍能反馈未解决或要求返修。
5. **费用不把维修卡住。** 原约定师傅费用由平台报销；临时费用双方同意可私下解决，纠纷再上平台。完工、报销、额外费用分别记录，不强制每一步审批或平台支付。
